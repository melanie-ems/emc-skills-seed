- Break things on purpose to learn

## 🆘 Getting Help

### When You're Stuck

1. **Read the error message** - It usually tells you what's wrong
2. **Check the lesson** - The answer might be there
3. **Use AI assistance** - Ask Copilot or ChatGPT for help
4. **Search online** - Stack Overflow has many answers
5. **Ask for help** - Instructors and classmates are there for you

### Common Issues

**Installation Problems?**
- See [Setup Guide](SETUP_GUIDE.md) troubleshooting section
- Check that Python is in your PATH
- Try restarting VS Code

**Code Not Working?**
- Check indentation (Python is sensitive!)
- Look for typos in variable names
- Make sure quotes match (" or ')
- Verify parentheses are balanced

**AI Suggestions Confusing?**
- Read the [AI Assistance Guide](resources/AI_ASSISTANCE_GUIDE.md)
- Try simpler prompts
- Ask AI to explain its suggestion
- Break problem into smaller pieces
