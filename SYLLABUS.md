# Course Syllabus - Python Programming for Non-Coders

## Course Information

**Course Title:** Python Programming for Non-Coders  
**Approach:** AI-Assisted Learning  
**Duration:** 8-10 weeks (self-paced)  
**Time Commitment:** 2-3 hours per week  
**Prerequisites:** None - no prior programming experience required!

## Course Objectives

By the end of this course, students will be able to:

1. **Foundational Programming Skills**
   - Write, read, and understand basic Python programs
   - Use variables, data types, and operators effectively
   - Implement control flow (conditionals and loops)
   - Create and use functions

2. **AI-Assisted Programming**
   - Effectively use AI coding assistants (GitHub Copilot, ChatGPT)
   - Write clear prompts and comments for AI assistance
   - Evaluate and verify AI-generated code
   - Debug with AI assistance

3. **Problem-Solving Skills**
   - Break down complex problems into smaller steps
   - Think algorithmically
   - Design solutions before coding
   - Test and verify code behavior

4. **Practical Application**
   - Build small programs to solve real-world problems
   - Work with data structures (lists, dictionaries)
   - Read from and write to files
   - Create interactive programs

- Write and run first Python program
- Experiment with AI code suggestions

- Navigate VS Code confidently

## Assessment Methods

This course uses **formative assessment** focused on learning, not grades:

### 1. Exercise Completion (Weekly)
- Complete exercises after each lesson
- Self-check against solutions
- Reflect on challenges and learnings

### 2. Code Reviews (Ongoing)
- Review your own code
- Identify improvements
- Refactor for clarity

### 3. Mini Projects (Weeks 8-10)
- Design and build a small program
- Apply multiple concepts
- Demonstrate understanding

### 4. Self-Reflection (Weekly)
- What did I learn?
- What was challenging?
- How did AI assistance help?
- What do I want to explore more?

## Grading Breakdown (If Grades Required)

If your institution requires grades, suggested breakdown:

- **Participation & Exercises:** 40%
  - Complete weekly exercises
  - Demonstrate effort and progress
  
- **Weekly Reflections:** 20%
  - Thoughtful responses
  - Evidence of learning
  
- **Mini Project:** 30%
  - Functionality
  - Code quality
  - Use of concepts
  - Documentation
  
- **Final Reflection:** 10%
  - Overall learning journey
  - Future goals

**Note:** The focus is on learning and growth, not perfection!

## Course Policies

### Pacing
- **Self-paced learning:** Move at your own speed
- **Suggested pace:** 1 lesson per week
- **Flexibility:** Take more time if needed on challenging topics

### AI Usage
- **Encouraged!** This is an AI-assisted course
- Use AI to learn, not to avoid learning
- Always understand the code you submit
- Document when and how you used AI

### Getting Help
- Use AI assistants as first resource
- Ask in course forums
- Attend office hours (if available)
- Collaborate with peers (with proper attribution)

### Academic Integrity
- Understand all code you submit
- Don't copy solutions from others without attribution
- Use AI as a learning tool, not a shortcut
- Be honest about your learning process

## Weekly Time Breakdown

**Estimated 2-3 hours per week:**
- Reading lesson material: 30-45 minutes
- Watching examples/demos: 15-30 minutes  
- Hands-on coding exercises: 60-90 minutes

**Tips for success:**
- Code a little bit every day (15-20 min)
- Don't binge-learn - consistency is key
- Take breaks when stuck
- Experiment and play with code
