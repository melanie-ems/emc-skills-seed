# Python Programming for Non-Coders
## AI-Assisted Learning Course

Repository for a programming course designed for students with limited or no coding experience. This course uses modern AI-assisted programming techniques inspired by "Learning AI assisted Python programming" by Leo Porter and Daniel Zingaro.

## 🎯 Course Philosophy

Instead of memorizing syntax, you'll learn to:
- Think computationally and solve problems
- Communicate effectively with AI coding assistants
- Understand and verify AI-generated code
- Build confidence through hands-on practice
- Create real programs from day one

## 📚 Course Structure

1. **[Lesson 1: Getting Started](lessons/lesson1_getting_started.md)** - Introduction to Python and AI-assisted programming
2. **[Lesson 2: Variables and Data Types](lessons/lesson2_variables.md)** - Storing and working with information
3. **[Lesson 3: Control Flow](lessons/lesson3_control_flow.md)** - Making decisions with if statements
4. **[Lesson 4: Loops](lessons/lesson4_loops.md)** - Repeating actions efficiently
5. **[Lesson 5: Functions](lessons/lesson5_functions.md)** - Writing reusable code
6. **More lessons coming soon!**

## 🚀 Getting Started

1. **Read the [Course Overview](COURSE_OVERVIEW.md)** to understand the learning approach
2. **Follow the [Setup Guide](SETUP_GUIDE.md)** to install Python, VS Code, and GitHub Copilot
3. **Start with [Lesson 1](lessons/lesson1_getting_started.md)** and work through at your own pace
4. **Complete exercises** after each lesson to practice your skills

## 🛠️ Prerequisites

- A computer with internet access
- Curiosity and willingness to learn
- **No prior programming experience required!**

## 💡 What Makes This Course Different?

**Traditional Approach:**
- Memorize syntax rules
- Look up documentation constantly
- Learn slowly through trial and error

**AI-Assisted Approach (This Course):**
- Focus on concepts and problem-solving
- Use AI assistants as learning partners
- Learn by understanding and modifying suggestions
- Write real programs faster

## 🎓 Learning Objectives

By completing this course, you will:
- Write Python programs to solve real problems
- Use AI coding assistants effectively
- Debug and fix common programming errors
- Think algorithmically about problem-solving
- Build confidence in your coding abilities

## 🌟 Tips for Success

1. **Code every day** - Consistency beats intensity
2. **Type code yourself** - Don't just copy-paste
3. **Experiment freely** - You can't break anything!
4. **Ask questions** - Use AI, forums, and instructors
5. **Be patient** - Everyone struggles at first
